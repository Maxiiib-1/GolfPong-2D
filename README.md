# Golf Pong 2D

### Videojuego 2D | C++ · SDL2 · Visual Studio 2022

## Descripción

Golf Pong 2D es un videojuego arcade desarrollado en C++ utilizando SDL2, inspirado en las mecánicas clásicas de Pong.

El juego presenta dos ambientaciones: una pista de hockey sobre hielo y un campo de golf. Ambas comparten una dinámica principal de juego, con diferencias visuales y ajustes en las hitboxes de colisión.

Este proyecto fue desarrollado como parte de mi formación en Desarrollo de Videojuegos en UADE.

## Modos de juego

### Hockey sobre hielo

Escenario inspirado en una pista de hockey, con arcos, jugadores, marcador y temporizador.

### Golf

Escenario de césped con hoyos y una configuración diferente de hitboxes, manteniendo la dinámica principal del juego.

## Tecnologías utilizadas

- **C++:** programación de la lógica del videojuego.
- **SDL2:** desarrollo de la aplicación 2D.
- **Visual Studio 2022:** entorno de desarrollo.

## Desarrollo y aprendizaje

Durante el proyecto trabajé en:

- Implementación de mecánicas de juego.
- Programación de colisiones y hitboxes.
- Integración de escenarios y elementos visuales.
- Pruebas y ajustes del comportamiento del juego.

El desarrollo me permitió aplicar conocimientos de programación en C++ y adquirir experiencia práctica con bibliotecas para videojuegos 2D.
